Las doce piezas de Escaque como SVG sueltos de 45×45 (mostrados a 180×180), dibujados a mano para este proyecto.

Cada archivo lleva su propio degradado con los valores de los tokens `piece-*`, ya resueltos: no heredan colores de la página. Úsalos para documentación, capturas o el README del repositorio. En la interfaz, pinta las piezas con el marcado de `components/Piece` para que los colores sigan a los tokens.

Nombres: `rey`, `dama`, `torre`, `alfil`, `caballo`, `peon` más `-blanca` o `-negra`.
