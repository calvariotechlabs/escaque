Lista de jugadas en notación algebraica, en dos columnas (blancas y negras) numeradas por jugada.

**Quién lo aporta.** Las jugadas ya escritas en español (`Cf3`, `Axe5+`) y la posición actual. La jugada actual lleva `aria-current="true"`, relleno `accent` y negrita. Cada jugada es un botón para saltar a esa posición.

**No hagas.** No muestres letras inglesas (N, B, R, Q, K) y no distingas la jugada actual solo por color. Sin jugadas, muestra «Aún no hay jugadas.» en `body-sm`.
