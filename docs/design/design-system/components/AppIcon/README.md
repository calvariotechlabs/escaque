Icono de la app y colores de tema de la versión instalada.

**Colores de tema.** `theme_color` y `background_color` del manifiesto, y la etiqueta `theme-color` de la página, usan `surface`: claro `#f1f3f5`, oscuro `#0f1218`. Así la barra del sistema y la pantalla de arranque se funden con la página. El fondo del icono es `board-ink` (`#0b2a38`) y la diagonal del alfil, `accent` claro (`#0b6e8a`); el alfil, `#f1f3f5`.

**Reglas.** Un solo dibujo, dos recortes: `any` (esquinas redondeadas) y `maskable` (a sangre, dibujo dentro del 80 % central). No se añade texto al icono. Legible a 32 px: la diagonal debe seguir viéndose.
