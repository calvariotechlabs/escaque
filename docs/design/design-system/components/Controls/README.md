Botones de la partida: Nueva partida, Girar tablero, Deshacer jugada y Rehacer jugada.

**Reglas.** «Nueva partida» es la única acción principal (`accent`). Alto mínimo de 44 px. Un botón desactivado usa `disabled`, texto `ink-muted` y borde discontinuo, no solo menos opacidad. Los rótulos son verbos en infinitivo.
