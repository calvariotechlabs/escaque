Diálogo para elegir la pieza al coronar un peón: dama, torre, alfil o caballo.

**Quién lo aporta.** El bando que corona (las piezas se pintan de su color) y el foco inicial en «Dama». Es un diálogo modal (`role="dialog"`, `aria-modal="true"`, `aria-labelledby` al título); Escape lo cierra y cancela la jugada; el foco vuelve a la casilla de origen.

**Reglas.** Cada opción lleva su nombre escrito bajo la pieza; la pieza es decorativa.
